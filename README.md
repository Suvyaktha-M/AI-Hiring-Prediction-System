# AI-Hiring-Prediction-System
A machine learning project for predicting hiring outcomes using candidate-related data, developed during the 3Skill Internship Program.

# Overview

An end-to-end machine learning project that predicts hiring outcomes using resume screening data. It analyzes candidate details such as skills, experience, education, certifications, salary expectations, project count, and AI score to predict whether a candidate will be hired or rejected.
Developed as part of the 3Skill Internship Program.

# Objectives:
Perform exploratory data analysis (EDA).
Analyze candidate-related features.
Build a machine learning model to predict hiring outcomes.

# Dataset:
The dataset contains 1,000 rows and 11 columns.
Key features: Skills, Experience, Education, Certifications, Job Role, Salary Expectation, Projects Count, and AI Score.
Target variable: Recruiter Decision — Hire or Reject.

# Technologies Used:
Python
Pandas and NumPy
Matplotlib and Seaborn
Scikit-learn
Google Colab

# Expected Outcome
A machine learning workflow for predicting hiring decisions from candidate-related features, demonstrating the application of data analysis and predictive modeling to recruitment.
